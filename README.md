## 📁 Estructura del Proyecto

```
/
├── index.html          # Landing page principal
├── styles.css          # Estilos personalizados + CSS variables
├── script.js           # JavaScript (tracking, animaciones, formularios)
├── schema.json         # Structured data para SEO
├── CNAME               # Configuración dominio GitHub Pages
├── robots.txt          # Reglas de crawling
├── sitemap.xml         # Sitemap XML
│
└── images/
    ├── Logo.webp
    ├── brands/         # Logos de marcas asociadas

    ├── services/       # Imágenes de servicios
    ├── wallpapers/     # Fondos hero

```

## 🚀 Desarrollo Local

```bash
# Opción 1: Python
python -m http.server 8000

# Opción 2: Node.js
npx serve .
```

Luego visitar `http://localhost:8000`
